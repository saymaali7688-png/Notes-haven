# 📚 Notes Heaven

Notes Heaven is a simple note-taking web application designed for students to create, organize, and manage their study notes in one place.

## ✨ Features

* 📝 Create, edit, and delete notes
* 📁 Organize notes into folders
* 💻 Add formatted code blocks
* 🖼️ Add images
* 🔍 Search and filter notes
* 🏷️ Add tags
* 💾 Persistent storage

## 🛠️ Tech Stack

* React
* TypeScript
* HTML & CSS
* Lucide Icons

## 🚀 Live Demo

[Open Notes Heaven](https://notes-heaven.ai.studio/)

## 🎯 Objective

To provide students with a simple and organized digital space for managing their study notes.
